Kara Task Dialog Refinement Report
Branch: main

Implemented
- Replaced the stacked, scrollable Add/Edit form with a compact native COSMIC
  dialog: heading, full-width title, one Due date / Priority / List row, modest
  Notes editor, and the standard Cancel / Save footer.
- Added three mutually exclusive symbolic priority controls for Low, Normal, and
  High. Normal remains the new-task default and editing restores the stored value.
  Controls have tooltips and accessible names; the priority data model is intact.
- Added a clickable calendar control backed by libcosmic's interactive calendar
  and popover. Choosing a date updates the same optional due-date text value.
- Added a separate date-entry module. It accepts compact digits, hyphen-separated
  or space-separated dates, pads month/day, infers the local current year when
  omitted, canonicalizes separated input on blur, preserves partial edits, and
  validates real dates including leap days.
  Invalid dates stay in the field, show an inline message and theme-derived error
  border, and prevent saving; correcting the value clears the error.
- Changed the unassigned task-list label to “Inbox”; named list titles are
  unchanged. The application titlebar now reads “KARA” while page headings remain
  unchanged.
- Kept the shared Add/Edit save path compatible with existing task assignments,
  priority, Matrix quadrant/order, and optional due dates. Storage schemas,
  sidebar/navigation, tray, and single-instance behavior were not changed.

Known limitations
- Visual fit, popover placement, keyboard focus and theme rendering need review
  in a running COSMIC session. The date field auto-formats continuous digit input
  when all eight digits are present and canonicalizes separated dates on blur;
  partial text remains untouched to preserve normal editing operations.
- The calendar popup uses libcosmic's standard calendar size. On unusually short
  displays, verify that the popup remains reachable and does not cover required
  dialog actions.

CachyOS COSMIC graphical acceptance checklist
1. At about 1280 x 800, open Add Task and Edit Task. Confirm the heading, full
   width title, single horizontal Due date / Priority / List row, modest Notes
   area, and Cancel / Save footer all fit without form scrolling.
2. At 800 x 600 and the minimum supported 640 x 560 window, confirm every field
   and action remains visible and usable; check that the metadata row does not
   clip or make its controls too narrow. Resize the window while the dialog is
   open and verify controls remain reachable.
3. Test priority selection by mouse and keyboard. Confirm Low uses a down arrow,
   Normal a minus, High an up arrow; selected state is visible independently of
   color, tooltips/accessibility names identify each option, Normal is selected
   for a new task, and Edit restores the existing selection.
4. Test date entry with 19990203, 1999 2 3, 1999-2-3, and 02-03. Confirm canonical
   YYYY-MM-DD display, current local year for the yearless form, and that empty
   remains optional. Try moving the cursor, editing/deleting partial text, and
   selecting/replacing the whole value without losing input.
5. Open the calendar icon. Navigate months in both directions, select a date,
   and confirm the field updates. Reopen it and verify its selected date matches
   the field; dismiss it without selection and confirm the field is unchanged.
6. Submit impossible dates including 2023-02-29 and 2024-04-31. Confirm the
   typed value remains, the due field gets a visible theme-consistent error
   border and nearby message, Save does not close the dialog, and a corrected
   value clears the error. Verify a valid leap day (2024-02-29) saves.
7. Confirm the list selector contains “Inbox” and named list titles only. Save
   tasks assigned to Inbox and a named list, then edit each and verify assignment
   and all task fields persist.
8. Confirm the centered application titlebar says “KARA” on Inbox, Today,
   Calendar, Lists, and Eisenhower Matrix, while the page heading retains its
   existing name.
9. Repeat the dialog, date picker, priority, and error checks under light and
   dark COSMIC themes. Tab through controls, verify focus indication, title focus
   on open, Enter-to-save behavior, and Cancel/Escape behavior.
10. Create and edit a Matrix task, confirm its quadrant/order and list assignment
    remain intact, then smoke-test existing tray close/reopen and second-launch
    activation behavior.
