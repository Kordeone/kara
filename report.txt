  existing shrink sizing and 280px desktop cap remain; long list labels continue
  contributing to the measured width. Condensed-mode visibility is unchanged.

  caught that during development; using natural Shrink height preserves the
  spacer in layout without adding a visible gap.

  the whole cell, native hover/pressed styling and a separate keyboard outline.
  No custom palette or button styling callbacks were introduced.
- Tooltips are below the cells. Names and selected accessibility state remain.
  Contextual subsections, remembered module state and sidebar toggle are unchanged.

Matrix preview
- The native DndSource drag icon now uses the bundled symbolic task-list icon
  in the normal theme foreground. It does not capture source priority or change
  dynamically during hover. The hovered quadrant communicates destination priority.
- The existing source-row feedback, destination highlight, capped insertion bar,
  grip threshold, routing IDs, clipping, payload validation and cancellation
  behavior remain. A valid drop still atomically updates priority and ordering.
- Native previews remain limited to the handle's 24px bounds by the locked API.
  No pointer tracking, animations, custom preview windows or new dependencies.

Exact CachyOS acceptance steps
1. Quit Kara using tray Quit so single-instance activation cannot restore an old
   binary. Transfer this integration candidate's source/Cargo.lock through Samba
   into a separate folder, preserving shared main and Luna's worktree. Build:
     cargo build --locked
     KARA_REFINEMENT_DATA=$(mktemp -d)
     XDG_DATA_HOME="$KARA_REFINEMENT_DATA" ./target/debug/kara
   Retain the temporary data directory for restart checks.
2. In a wide window, confirm the sidebar has its previous width and four equal
   module cells span its inner width. Icons must be horizontally/vertically
   centered. Click near each cell's left/right edges, not just the glyph: all
   edges should switch to the corresponding module and highlight its full cell.
3. Check the selected rounded background, hover and keyboard Tab/Shift+Tab focus
   are distinguishable. Activate modules by keyboard. Hover each tooltip: labels
   should appear below the selector without covering the header controls.
4. Switch among Tasks, Board, Matrix and Pomodoro and back. Verify contextual
   subsections, remembered list selection, Matrix Lists expansion and Tasks list
   pins/collapse remain unchanged. Add a long named list to exercise wider native
   navigation measurement; cells must still span the sidebar without clustering.
5. Repeat maximized, narrow and short windows, light/dark themes and 100%/200%
   scaling. Toggle the native sidebar off/on and cross the condensed breakpoint.
   Confirm no collapsed/empty panel, cropped controls, overlapping cells or gaps.
6. In Matrix, create active/completed tasks across all priorities. Drag each
   from its grip and hover another quadrant. The moving badge must stay the same
   neutral task-list symbol, never show a misleading old priority flag. Original
   row feedback, destination tint and exact insertion marker must remain visible.
7. Drop before first/middle rows and on headers/backgrounds to append. Confirm
   the actual task receives the destination flag and correct rank, with stable
   identity, list, completion, dates and notes. Test same-quadrant reordering,
   completed tasks, empty targets and scrolled quadrant/narrow-window content.
8. Cancel via Escape, drop outside valid targets, then drag again immediately.
   Badge/highlights must clear with no data change or duplication. Check existing
   keyboard priority/Up/Down fallback, task editing and normal Tasks sorting.
9. Quit/relaunch with the same XDG_DATA_HOME. Confirm priorities/order and task
   fields persist. Smoke-test tray Open/Quit and second-launch activation.
