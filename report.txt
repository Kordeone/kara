Kara Tasks toolbar refinement

Implementation
- Replaced the text dropdown in Inbox, Today, and named-list toolbars with a
  compact COSMIC icon button that opens a native popover containing Creation
  date, Due date, Priority, and Name choices. A check icon marks the active
  choice; the icon-only trigger has a tooltip and accessible name.
- Added an adjacent icon-only direction toggle with ascending/descending
  symbolic icons, state-specific tooltip, and accessible name. Natural defaults
  preserve existing behavior: Creation date newest-first, Due date earliest-
  first, Priority P3-first, and Name A–Z. Selecting a different mode selects
  that mode's natural default; reselecting the active mode preserves its current
  direction. Reversing date sorts leaves undated and unknown-creation-time tasks
  last and stable.
- Moved Show Completed to the far right of the toolbar using a flexible spacer.
  Its label, default, filtering behavior, and persistence remain unchanged.
- Bundled the mode, ascending, descending, and active-mode check symbols as
  embedded theme-tinted SVGs. The sidebar and its existing bundled icons were
  not changed.
- Persisted sort direction alongside the existing mode and completed-filter
  preferences. Matrix ordering remains outside the task-view sort operation.

Storage compatibility
- Bumped the existing atomic JSON document from version 5 to version 6 to
  record direction explicitly. Existing v4 and v5 documents retain their
  established sort defaults; for v5 files without direction, the selected
  mode's natural direction is inferred.
- Before upgrading v4 or v5 data on its first write, Kara saves and verifies an
  exact recoverable copy at `tasks.json.pre-tasks-v6.bak`. Older v1–v3 migration
  backup behavior remains intact. No live task data was used in migration tests.

CachyOS COSMIC graphical acceptance checklist
1. Open Inbox, Today, and a named list. Confirm the toolbar has two compact
   icon-only sorting controls aligned left and Show Completed aligned at the
   far right, with no long sort text visible until the mode popover opens.
2. Open the mode popover by mouse and keyboard. Confirm it shows the four
   expected labels, clearly marks the active mode, uses an opaque theme surface,
   and closes on selection, Escape, and outside click.
3. Confirm the direction icon and tooltip identify current state and the
   opposite action. Test both directions for creation date, due date, priority,
   and name, including undated/legacy tasks remaining last for date sorts.
   Confirm equal sort keys retain relative order and completed tasks follow the
   same chosen ordering.
4. Confirm each mode initially uses its natural existing order; changing modes
   restores that mode's natural direction, while reselecting the current mode
   leaves a manually reversed direction intact.
5. Toggle Show Completed in Inbox, Today, and a named list. Confirm it remains
   on the right, updates rows immediately, preserves original context, and
   persists after restart. Verify Today still excludes future and undated tasks.
6. Verify sort mode and direction persist after restart. On a disposable copy
   of a v5 data file, confirm the v6 upgrade's `.pre-tasks-v6.bak` is byte-exact.
   Confirm the Matrix's task order is unchanged by task sorting.
7. Inspect narrow and normal window sizes, light/dark themes, keyboard focus,
   tooltip visibility, icon clarity, popover placement, and toolbar clipping.

Known limitations
- Graphical appearance, focus traversal, accessibility announcements, and
  popover placement require the owner's CachyOS COSMIC review.
- Calendar remains its existing placeholder and has no task sorting toolbar.
